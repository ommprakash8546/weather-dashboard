# Weather Dashboard

A responsive React weather dashboard that provides current weather conditions and a 5-day forecast using the OpenWeather API.

## Live Demo

https://weather-dashboard-one-swart.vercel.app/

## Features

- Search weather by city
- Current location weather
- Current temperature
- Weather condition and icon
- Feels-like temperature
- Humidity
- Wind speed
- Atmospheric pressure
- Visibility
- 5-day weather forecast
- Recent searches
- Clear recent searches
- Refresh weather
- Last updated time
- Local Storage persistence
- Loading indicator
- Error handling
- Responsive mobile-friendly design

## Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS
- OpenWeather API
- Local Storage
